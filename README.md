# 歴史総合③ 確認アプリ

GitHub Pages 用の静的サイトです。

## 公開方法
1. このフォルダの中身を GitHub リポジトリのルートにアップロードします。
2. GitHub の `Settings` → `Pages` を開きます。
3. `Build and deployment` の Source を `Deploy from a branch` にします。
4. Branch を `main`、Folder を `/ (root)` にして保存します。
5. 数分後、表示された GitHub Pages の URL からアクセスできます。

メインファイルは `index.html` です。
